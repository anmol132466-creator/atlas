Operational Scope & Administration Mandate

The Admin Tool for Live Area Surveillance (A.T.L.A.S.) is an embedded server-side administrative extension developed strictly for Minecraft server moderation, performance telemetry, and live area observation. Its function is to assist authorized operators in maintaining fair play, verifying anticheat flags, protecting builds from griefing, and ensuring community safety.

By connecting to this Minecraft server, players participate in shared world gameplay where game-state variables (such as entity locations, inventory contents, chat messages, and block updates) are transmitted to the server software as part of standard Minecraft protocol and presented to authorized administrators through this tool.

Guaranteed Self-Containment
A.T.L.A.S. does not connect to external servers, cloud databases, or advertising networks. Player data never leaves this specific host server environment.

Voice Telemetry & Audio Monitor Protocols

When an administrator enables the Spyglass Audio Monitor, the following voice handling protocols are strictly enforced:

  • Local Network Hook: The audio daemon hooks into the server's Simple Voice Chat UDP network pipeline (default port 27995) or integrated voice socket.
  • Spatial Range Filtering: Only voice packets originating within the operator's active radar circle (bounded 10m–100m) in the matching dimension are intercepted. Voice traffic outside this boundary is discarded immediately.
  • In-Memory Decoding: Intercepted Opus packets are decoded in volatile memory into 48kHz mono PCM streams and transmitted through authenticated WebSocket connections directly to the operator's browser.
  • Strict Non-Recording Guarantee: Under no circumstances does A.T.L.A.S. record audio conversations to disk, write voice logs, or transmit acoustic telemetry off-site. Once an audio frame completes playback in the browser's WebAudio jitter buffer, it is permanently wiped from RAM.
  • Two-Way Transmission & Broadcast: When an administrator transmits voice (either directly to nearby players or via server-wide broadcast), the microphone stream is encoded into Opus/PCM and forwarded strictly into game voice channels in compliance with server rules.

Cryptographic Authentication & Instance Control

Access to the A.T.L.A.S. surveillance dashboard is protected by cryptographic token validation and server-side session registry barriers:

  • Persistent Instance Token: Generated exclusively through the server console or verified administrator in-game via /atlas link. The link remains active for convenience across browser refreshes and reconnects.
  • Instant Revocation (/atlas unlink): Administrators can immediately terminate all active web sessions, disconnect open WebSockets, and invalidate issued link tokens at any time by executing /atlas unlink or /atlas close.
  • IP Rate Limiting: A built-in token-bucket rate limiter defends the HTTP and WebSocket endpoints against brute-force attacks and socket flooding.
  • Server Shutdown Invalidation: All active sessions and volatile link tokens automatically terminate whenever the Minecraft server restarts.
Operator Link Confidentiality
Dashboard URLs contain sensitive access tokens. Operators must never share links publicly. If a link is compromised, run /atlas unlink immediately to shut down the instance.

World Generation, Map Tiles & Block Wave Audits

A.T.L.A.S. renders a real-time slippy tile map of the Minecraft world directly from world chunk data and the server seed:

  • Real Seed Biome Alignment: Procedural background terrain is calculated from the authentic world seed and vanilla Minecraft biome engine to match actual game terrain.
  • Unexplored Territory Defocus: Unexplored, ungenerated chunks are rendered with a smooth defocus blur to preserve discovery and indicate uncharted terrain.
  • Live Block Buffer: When players place or break blocks, events are temporarily buffered in RAM to reflect live modifications on map tiles before disk saves occur.
  • Live Block Ripples: Block placements and breaks produce animated tactical radar waves on the live map to assist moderators in identifying griefing, mining clusters, and combat zones. These ripple coordinates evaporate after a 5-second lifespan.

Frequently Asked Questions

Is any player voice chat recorded or saved to files?
No. Audio packets are processed solely in volatile memory for live spatial monitoring within the operator's active radar radius. Once played through the browser audio engine, packets are purged immediately. No MP3, WAV, or Opus files are ever written to the disk.
Does this dashboard send telemetry to external companies?
No. A.T.L.A.S. is 100% self-hosted and self-contained within this Minecraft server. All WebSockets, HTTP tile servers, and telemetry daemons communicate directly between your server and the authenticated browser.
How can an administrator instantly revoke active dashboard access?
Run /atlas unlink (or /atlas close) in the server console or in-game. This immediately invalidates all issued link tokens, clears active sessions, and disconnects all connected web dashboards.
