Why does my browser show "Not Secure"?

Web browsers (Chrome, Edge, Firefox) automatically display "Not secure" for any unencrypted HTTP connection made to an IP address because it lacks a registered commercial domain and third-party SSL certificate. Your Minecraft server is NOT compromised or vulnerable.

Active Built-in Defenses

  • One-Time HMAC Auth: All HTTP and WebSocket operations require cryptographically random tokens with strict expiry.
  • Session Isolation: Virtual-threaded sandboxing with no disk or OS command execution.
  • Token-Bucket Rate Limiter: Automatically defends against brute-force port scanners and unauthorized requests.
  • Defensive Headers: nosniff, SAMEORIGIN, and strict-origin-when-cross-origin enforce browser sandbox protection.

How to Clear the Browser Warning Without Buying a Domain

1. Host Machine (Zero Warnings): Access via http://localhost:27994. Browsers recognize localhost as an intrinsically trusted Secure Context.
2. Remote LAN Access (Chrome/Edge): Visit chrome://flags/#unsafely-treat-insecure-origin-as-secure, add this server's IP address, and click Relaunch. This permanently removes the warning for this dashboard on that browser.
